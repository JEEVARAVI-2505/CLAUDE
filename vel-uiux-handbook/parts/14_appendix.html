A. Glossary (plain language)

TermMeaning
UIUser interface: what the user sees and touches (colours, text, buttons, layout)
UXUser experience: how easy, clear and satisfying it is to get something done
HCIHuman-computer interaction: the study of how people use computers
Visual hierarchyThe order in which the eye notices things
WireframeA simple, greyscale layout showing structure, not style
PrototypeA clickable model that behaves like the product
PersonaA fictional-but-evidence-based profile that summarises a real user group
User journeyThe steps and feelings a user goes through to reach a goal
Information architectureHow content is organised and labelled
ComponentA reusable interface piece (button, card, input)
VariantA version of a component (hover, disabled, large)
Auto LayoutFigma feature that resizes and spaces content automatically
Design token / VariableA named value (colour, spacing) used everywhere instead of a raw number
Design systemTokens + components + rules + documentation
WCAGWeb Content Accessibility Guidelines; levels A, AA, AAA
Contrast ratioMeasure of difference between text and background brightness
HandoffGiving developers everything needed to build the design
SoWStatement of Work: the signed scope, deliverables, exclusions and limits
Gate (G1-G10)A mandatory approval before the next stage may start

C. Knowledge assessment 1 (Week 1) with answer key

#QuestionAnswer
1Give one difference between UI and UX.UI is what is seen and touched; UX is the overall ease and outcome of using it.
2Name four tools that create visual hierarchy.Size, weight, colour, contrast, position, space (any four).
3What is the squint test?Blur or squint at a screen; the most important elements should still stand out in the right order.
4Minimum contrast for normal text under WCAG AA?4.5 : 1.
5Does #B9801A text on white pass AA? Why?No. Calculated ratio is 3.41 : 1, below 4.5 : 1.
6Why not use colour alone to show an error?Some users cannot distinguish the colour; add an icon and text (WCAG 1.4.1).
7Who approves your Week-1 deliverable?Your mentor.
8You only interviewed 1 person. Can the persona say "most users prefer X"?No. Never state findings you did not collect; record it as a single observation.
9Where is the master design file kept?In Figma, not in the repository.
10What must you do before sharing a Figma link with a client?Check permissions (view or comment only), confirm the file is client-ready and approved by the reviewer.
