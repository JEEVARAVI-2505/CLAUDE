5. VEL Design Standards

These standards style VEL's own documents, portal and pitch material, and are the practice template for training projects. Client projects use the client's brand; use this file to learn how a system is structured. Colours were sampled from the VEL logo and the existing Cloud & DevOps Playbook; the token file is design-tokens/tokens.json.

Contrast check (calculated, WCAG 2.2 SC 1.4.3 and 1.4.11)

Ratios are computed from the exact hex values using the WCAG relative-luminance formula. Normal text needs 4.5 : 1; large text (18pt+, or 14pt bold) and UI component borders/icons need 3 : 1.

{{CONTRAST}}
Colour rules that follow from the numbers
  • Gold-600, magenta-400 and emerald-500 fail for text on white. Use them for decoration or large graphics only, or switch to the 700 shade.
  • Gold-500 is a highlight on navy backgrounds only (navy text on it passes).
  • Never convey meaning by colour alone: status always carries an icon or a text label as well.
  • Primary action is always Lotus Magenta-600 with a white label. One primary button per view.
