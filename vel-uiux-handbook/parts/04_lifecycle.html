Rules for gates
  1. An approval is valid only if it is written (email, signed document or tracked comment) and stored in delivery/ or the portal approval history.
  2. "Looks good" in a call is not approval. The PM records it in writing within one working day.
  3. Changes after a gate are change requests: written, estimated, approved, then done. Revision limits come from the SoW.
  4. Every project has a unique ID, format VEL-UX-YYYY-NNN (for example VEL-UX-2026-001).
