Appendix B: Glossary

TermMeaning
AssetAnything of value to protect: system, data, application, account, process
Authorisation (testing)Written permission from the asset owner defining scope, methods and time
Attack surfaceAll points where an unauthorised party could try to enter or extract data
CIA triadConfidentiality, integrity, availability
CVE / CVSSPublic vulnerability identifier / standard severity scoring system
DAST / SAST / SCATesting a running app / analysing source code / checking third-party components
EDREndpoint detection and response software
False positiveA scanner alert that is not a real vulnerability
HardeningReducing a system's attack surface by tightening configuration
IAMIdentity and access management
IDS / IPSSystem that detects / detects and blocks suspicious network activity
Least privilegeGiving only the access needed to do the job
MFAMulti-factor authentication: two or more kinds of proof of identity
Residual riskRisk that remains after controls are applied
RoERules of Engagement, the signed testing rules for an engagement
SIEMSecurity information and event management: central log analysis
SnapshotSaved state of a virtual machine that can be restored
SSRF / CSRF / XSSServer-side request forgery / cross-site request forgery / cross-site scripting (concepts taught on vulnerable training apps)
Stop-workImmediate halt of testing under agreed conditions
Threat modelStructured analysis of what can go wrong, who might cause it, and what stops it
Tier (T0–T3)VEL risk classification of testing activity
Trust boundaryLine where data or control passes between zones of different trust

Appendix D: Beginner quick-reference card

Before I run anything, I ask…If the answer is "no" or "not sure"
Is this target in my signed authorisation or Lab record?Stop. Do not run it.
Is today and now inside the permitted window?Stop.
Does my authority level allow this tier?Ask the Security Lead.
Do I know what traffic this will send and what it could break?Read the module; ask the mentor.
Have I backed up and can I roll back?Take the snapshot or backup first.
Where will the output be stored, and does it contain secrets?Use the restricted store; redact.
