Trainee code of conduct

  • Ask early; stuck for 30 minutes means ask.
  • Treat client data and credentials as sacred.
  • Write down what you did: if it is not documented, it did not happen.
  • Destroy sandbox resources after each lab to avoid cost.

B. Incident response (first 30 minutes)

  1. Acknowledge the alert; assign an incident lead.
  2. Assess severity and user impact; open an incident record.
  3. Communicate to the client with what is known, what is being done, next update time.
  4. Mitigate first (rollback, scale, failover); find root cause after service is restored.
  5. Record timeline and actions.
  6. Post-incident review within days: blameless, root cause, actions with owners.
