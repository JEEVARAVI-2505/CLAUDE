# Privacy

* Documents are processed **on this computer only**. DocuMind has no telemetry, no advertising, no accounts and no automatic updates or uploads.
* The only network traffic DocuMind itself creates is a connection to the AI server you configure, which must be on this computer (`127.0.0.1`) unless an administrator explicitly allows otherwise.
* Data lives in the data folder shown in *Settings › Data & backup*. Anyone who can sign in to this Windows account can read it – protect the account, and consider BitLocker.
* Logs never contain document text. Names of people or companies in files are not logged; file names are not logged either.
* Deleting a document overwrites its stored original and removes all its data. Earlier exports and backups are separate files you control.
* DocuMind never sends email or transmits documents. Future integrations would require explicit configuration and consent.
