# VEL Custom Software & Enterprise Solutions Department Handbook (VEL-CSE-001 v1.0)

Module M0 of the department curriculum. Generated from `build/` (Python + Chromium).

| Output | File |
|---|---|
| Handbook PDF (88 pp, watermarked) | `output/VEL-Custom-Software-Enterprise-Handbook.pdf` |
| Standalone responsive HTML (sidebar, search, print) | `output/VEL-Custom-Software-Enterprise-Handbook.html` |
| 13 stand-alone template PDFs (Appendices A–M) | `output/templates/` |

Rebuild: `python3 build/build_all.py` (needs Python 3, Node + Playwright Chromium, poppler-utils).
Content lives in `build/c0*.py`; costing numbers come from `build/costing.py` (assumptions, INR, ex-GST).
