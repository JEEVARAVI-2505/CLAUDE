# Contributing
- Branches: `feat/<id>-<name>`, `fix/<id>-<name>`, `hotfix/<id>-<name>`; never commit to `main` directly.
- Commits: Conventional Commits (`feat(scope): summary`).
- PRs: small, template completed, CI green, reviewed by someone else, squash-merge.
- Never commit secrets or customer data. If it happens: rotate first, then tell the Technical Lead.
- Definition of done: see handbook Section 6.
