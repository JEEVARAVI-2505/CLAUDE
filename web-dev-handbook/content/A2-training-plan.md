A 90-day plan (13 weeks). Daily rhythm: **2 h reading + 4 h hands-on + 30 min notes**, 15-minute daily mentor check-in, 45-minute weekly review. Adjust pace with the mentor - gates matter more than dates.

| Week | Level / module focus | Hands-on deliverable | Gate / review |
|---|---|---|---|
| 1 | Onboarding; L1.1-L1.3 (web architecture, browser/server, HTTP) | Dev environment; first PR; request-path diagram | Gate 1 |
| 2 | L1.4-L1.9 (DNS, hosting, front/back, DB concepts, APIs, responsive) | DNS plan; hosting ADR; API collection; Level 1 quiz | Level 1 sign-off |
| 3 | L2.1-L2.2 (HTML5, CSS3); L2.7 DevTools | **Project 1** - responsive business site (start) | Mid-point review |
| 4 | L2.5-L2.6 (Flexbox/Grid, accessibility); L2.3 JavaScript (start) | Project 1 completed and deployed; accessibility audit | Project 1 accepted |
| 5 | L2.3-L2.4 (JavaScript, TypeScript) | Task-list app in TypeScript | Weekly review |
| 6 | L2.8-L2.9 (React, Next.js) | **Project 2** - multi-page corporate site | Project 2 accepted - **Gate 2** |
| 7 | L3.1-L3.2 (FastAPI/Django/Node, REST design); L4.1-L4.2 (Postgres, design) | API specification + ER design for Project 3/4 | Spec review |
| 8 | L3.3-L3.5 (authentication, authorisation, business logic) | **Project 3** - auth application | Attack tests |
| 9 | L3.6-L3.9 (validation, errors, uploads, e-mail); L4.3-L4.5 (relations, SQL, indexes) | Project 3 accepted; SQL test | Project 3 accepted - **Gate 3** (with L4) |

| 12 | L5.8-L5.11 (cloud, logging, monitoring, security) | Project 5 deployed; **Project 6** SaaS dashboard | Security review - **Gate 4** |
| 13 | Capstone - full lifecycle with a trainer-client | **Project 7** simulated client project; oral defence | **Gate 5 - Delivery Readiness Certificate** |

## If you fall behind

Tell your mentor in the first week of slipping. Options: reduce breadth (keep the essential modules), add mentor pairing sessions, extend the schedule - but **never** skip a gate or sign work you cannot explain.
