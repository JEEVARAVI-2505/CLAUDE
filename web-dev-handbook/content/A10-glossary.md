| Term | Meaning |
|---|---|
| **A record / AAAA** | DNS record mapping a name to an IPv4 / IPv6 address |
| **ADR** | Architecture Decision Record - short document capturing a technical decision and its reasons |
| **API** | Application Programming Interface - a defined way for programs to talk to each other |
| **ARIA** | Accessible Rich Internet Applications - attributes that add accessibility meaning when HTML alone is not enough |
| **ARR / MRR** | Annual / Monthly Recurring Revenue |
| **Argon2id** | A modern, slow, memory-hard password-hashing algorithm |
| **Authentication / Authorisation** | Proving who you are / deciding what you may do |
| **Backup / restore** | A copy of data / the act of bringing it back; only a tested restore proves a backup |
| **Branch** | An independent line of development in Git |
| **CDN** | Content Delivery Network - caches content close to users |
| **CI / CD** | Continuous Integration (build and test every change) / Continuous Delivery or Deployment |
| **CMS** | Content Management System |
| **Contingency** | Reserve added to an estimate for uncertainty |
| **Contribution margin** | Price minus variable costs - what a project adds toward fixed costs and profit |
| **CORS** | Cross-Origin Resource Sharing - browser rule controlling which sites may call an API |
| **CRUD** | Create, Read, Update, Delete |
| **CSP** | Content Security Policy - header that restricts what a page may load or run |
| **CSRF** | Cross-Site Request Forgery - tricking a browser into sending an unwanted request |
| **DNS** | Domain Name System - turns names into IP addresses |
| **Docker / container** | Tool and format for packaging an app with its dependencies so it runs the same everywhere |
| **ER diagram** | Entity-Relationship diagram of database tables and relations |
| **Gate** | A mandatory approval point; work does not continue until it is signed |
| **Gross margin** | (Price - direct cost) / price |
| **HSTS** | HTTP Strict Transport Security - tells browsers to use only HTTPS |
| **HTTP / HTTPS** | The web protocol / HTTP over TLS encryption |
| **IaC** | Infrastructure as Code (Terraform/OpenTofu) |
| **Idempotent** | Repeating the operation has the same effect as doing it once |
| **IDOR** | Insecure Direct Object Reference - reading another user's record by changing an id |
| **INP / LCP / CLS** | Core Web Vitals - interaction responsiveness, loading speed, visual stability |
| **JWT** | JSON Web Token - signed token carrying claims |
| **Markup** | (Price - cost) / cost; not the same as margin |
| **Migration** | Versioned script that changes the database schema |
| **MFA** | Multi-Factor Authentication |
| **OWASP** | Open Worldwide Application Security Project - security standards and guidance |
| **PR** | Pull Request - a proposed change reviewed before merging |
| **RBAC** | Role-Based Access Control |
| **REST** | Architectural style for APIs using resources and HTTP methods |
| **RPO / RTO** | Recovery Point Objective (acceptable data loss) / Recovery Time Objective (acceptable downtime) |
| **SEO** | Search Engine Optimisation |
| **SLA / SLO** | Service Level Agreement / Objective - agreed service targets |
| **SOW** | Statement of Work - the agreed scope, price and terms |
| **SQL injection** | Attack that inserts SQL through unvalidated input; prevented by parameterised queries |
| **SSR / SSG** | Server-Side Rendering / Static Site Generation |
| **TLS** | Transport Layer Security - encryption used by HTTPS |
| **UAT** | User Acceptance Testing - the client verifies the product against acceptance criteria |
| **WCAG** | Web Content Accessibility Guidelines (target: 2.2 level AA) |
| **XSS** | Cross-Site Scripting - injecting script into a page viewed by other users |
