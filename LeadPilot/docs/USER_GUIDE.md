# LeadPilot AI - user guide

## 1. First start
The setup wizard asks for your name, company, country (for phone numbers without a country code) and an optional administrator PIN. Your 14-day free trial (up to 200 leads) starts automatically.

## 2. Find leads (AI Lead Finder)
1. Type **what you sell**, **who you want to reach**, **where**, and **how many prospects**.
2. Press **Find leads**. The app searches the enabled sources (OpenStreetMap by default) and, if allowed, reads each company's own website for public phone/e-mail.
3. Review the table: every row shows a relevance score; click a row to see *why*. Rows that look like leads you already have are flagged and not pre-selected.
4. Press **Save selected as leads**. A campaign is created for this search. Nothing is stored before you press Save.

If no source can be reached (offline, server busy) the app says so and adds nothing. It retries politely and keeps other sources going.

## 3. Lead Database
Search, filter, sort, page; select rows for bulk **status**, **assign**, **export** or **delete**. Click a Lead ID (LD-000001…) to open the lead: edit fields, see the **evidence** (value, source page, time, confidence), **timeline**, **follow-ups** and **outreach drafts**.

## 4. Duplicates
Duplicate Manager → **Scan**. Review each pair side by side; **Keep left/right** merges the other record into it (empty fields are filled, nothing overwritten) and **Undo merge** restores both. *Not duplicates* hides the pair for good.

## 5. Enrichment and checks
AI Enrichment lists leads missing phone/e-mail/website and reads their own sites. Values are applied only when the page's company name matches and the field is empty; everything else is saved as a suggestion with its source. **Run contact checks** tests e-mail domains (DNS) and websites.

## 6. Qualification
Lead Qualification shows the ranked leads, the plain-English reasons for each score, and lets you change the weights and Hot/Warm/Cold thresholds, then re-score everything. Scores are *relevance*, not purchase intent.

## 7. Follow-ups, campaigns, assistant
Follow-up Manager lists tasks (overdue in red) with suggested next actions. AI Assistant answers from your database ("Show my top 20 prospects", "Identify duplicate records", …). Drafts open in your own mail app or WhatsApp - you press Send.

## 8. Import / export / backup
Import Centre: choose .xlsx/.csv → preview → map columns → validate → confirm → report. Export Centre: Excel, CSV, PDF. Backup & Restore: one-file backups, optionally password-encrypted.

## 9. Licence
About & Licensing shows your computer ID and activates a licence key offline.
